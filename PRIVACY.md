# Privacy policy

Effective date: September 3, 2026

Aparte does not collect, transmit, sell, or share personal data. It has no account, analytics, advertising, telemetry, cloud sync, or network connection.

Your writing is stored as Markdown on your Mac. Aparte keeps its working document in its private application storage. When you choose Save, macOS asks you where to write a separate Markdown file. Aparte accesses only the location you select for that save.

Aparte reads the clipboard only when you paste, copy, or open the Link control. The Link control uses the current clipboard value only to suggest a web address. Aparte does not monitor clipboard changes or send clipboard contents anywhere.

Questions about this policy can be sent to [pocarles@me.com](mailto:pocarles@me.com).
