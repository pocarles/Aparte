# Privacy policy

Effective date: September 11, 2026

Aparte has no account, analytics, advertising, telemetry, or cloud sync. It does not collect or sell your writing.

Your writing is stored as Markdown on your Mac. Aparte keeps its working document in its private application storage. When you clear a nonempty pad, it also retains one local recovery copy until you clear another nonempty draft or choose Discard recovery copy. Your shortcut, text zoom, and counter preference stay on your Mac. Launch at login is optional and can be turned off from the menu. When you choose Save, macOS asks you where to write a separate Markdown file. Aparte accesses only the location you select for that save.

Aparte reads the clipboard only when you paste, copy, or open the Link control. The Link control uses the current clipboard value only to suggest a web address. Aparte does not monitor clipboard changes or send clipboard contents anywhere.

Aparte sends the pad's Markdown only when you choose Send to endpoint…. The request goes only to the address you typed. That address is stored on your Mac so the field can be filled in next time. Aparte keeps no copy of what it sent and does not send it anywhere else. No account or token is involved.

Direct-download builds use Sparkle to check GitHub for updates once a day, or when you choose Check for Updates…. These HTTPS requests expose normal connection information, such as your IP address, to GitHub and its download providers. Sparkle system profiling is disabled. Update requests contain no writing or clipboard contents. Aparte does not install updates automatically by default. Local builds and App Store builds contain no Sparkle updater; App Store updates are handled by Apple.
