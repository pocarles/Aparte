# Aparte support

Aparte is a macOS menu bar writing pad. Press Option-Space to show or hide it. Press Escape to dismiss it.

If the global shortcut is already used by another app, click Aparte's text-cursor icon in the menu bar to open the pad.

For installation help or a bug report, open a
[GitHub issue](https://github.com/pocarles/Aparte/issues). For a private question,
email [pocarles@me.com](mailto:pocarles@me.com). Report security problems through
the private process in [SECURITY.md](SECURITY.md), not a public issue.
