# Contributing

Keep Aparte small, native, local, and quiet at idle.

1. Open an issue before changing the product boundary.
2. Create a focused branch.
3. Add tests for changed document behavior.
4. Run `make check`.
5. Keep third-party code and notices accurate.

Do not add telemetry, accounts, cloud storage, network dependencies, Electron, or a notes-library interface without an explicit product decision.
